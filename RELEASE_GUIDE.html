# 柠檬TV v1.0.1

> 🍋 轻量级智能电视直播应用

## 📦 下载说明

### APK 文件
- **LemonTV-v1.0.1-release.apk** - 推荐下载（通用版，支持所有设备）
  - 包名：`com.lemontv.lite`
  - 版本号：1.0.1
  - 最低 Android 版本：5.0 (API 21)
  - 支持架构：armeabi-v7a, arm64-v8a, x86_64

### 安装方式
1. 下载 APK 文件到电视或盒子
2. 使用文件管理器打开
3. 允许安装未知来源应用
4. 点击安装

## ✨ 本版本特性

### 🎯 核心功能
- ✅ 智能直播源管理，支持自定义 M3U/TXT 格式
- ✅ 节目单（EPG）多级智能降级加载
  - 优先使用直播源内嵌 EPG 地址（支持逗号分隔多个地址）
  - 失败后降级到 APP 设置的 EPG
  - 最后使用默认 EPG
- ✅ User-Agent 智能识别（从直播源自动提取）
- ✅ 一键刷新直播源，更新缓存
- ✅ 多线路切换，播放失败自动切换
- ✅ 经典选台模式（数字键快速选台）
- ✅ 支持局域网推送直播源（10481 端口）

### 🎨 界面优化
- ✅ 全新主题黄色（#FDDD0E）Toast 提示框
- ✅ 优化启动画面，品牌统一
- ✅ 菜单键快速呼出设置和操作面板
- ✅ 选中高亮效果统一

### 🔧 技术改进
- ✅ 缓存机制优化，自动创建缓存目录
- ✅ 支持 M3U 多 EPG 地址解析（逗号分隔）
- ✅ GitHub 加速代理更新为 `https://hk.gh-proxy.org/`
- ✅ 网络请求重试机制（最多 10 次）
- ✅ 文件缓存容错和重试机制

## 🐛 已修复问题
- ✅ 修复缓存目录不存在导致的播放失败（403 错误）
- ✅ 修复 EPG 地址只读取第一个的问题
- ✅ 修复直播源热更新后新增频道不显示

## 📱 使用说明

### 快捷键
- **菜单键** - 打开快速面板（刷新源、画面比例、设置等）
- **数字键** - 经典选台模式
- **上下键** - 切换频道
- **左右键** - 切换线路（多线路时）
- **返回键** - 退出/返回上级

### 推送直播源
1. 确保电视和手机在同一局域网
2. 打开设置界面查看推送地址（例如：`http://192.168.1.100:10481`）
3. 在浏览器中打开该地址
4. 输入直播源地址并推送

### 刷新源
1. 按遥控器**菜单键**打开快速面板
2. 选择"**刷新源**"按钮
3. 系统会清除缓存并重新加载最新直播源

## ⚙️ 配置说明

- **包名**：com.lemontv.lite

- **默认 EPG**：http://epg.51zmt.top:8000/e.xml.gz
- **HTTP 服务端口**：10481

常见问题 FAQ

Q1: 构建时提示 "Unable to delete directory"

解决方案：
  • 使用 build-release.bat（已移除 clean 任务）
  • 或使用 build-release-enhanced.bat（自动清理）
  • 手动关闭文件资源管理器和 Android Studio

Q2: 上传后文件名被修改了怎么办？

解决方案：

GitHub 不会修改上传的文件名。如果看到不同的文件名， 可能是浏览器下载时自动添加的。原始文件名在 Release 页面始终保持不变。

Q3: APP 检测不到更新

检查项：
  1. 确认 Release 勾选了 "Set as the latest release"
  2. 访问 API 地址确认能返回数据：
    https://api.github.com/repos/jia070310/lemonTV/releases/latest
  3. 检查 APP 中的版本号配置是否正确
  4. 清除 APP 缓存后重试

Q4: 如何撤回或删除 Release？

操作步骤：
  1. 访问 Releases 页面
  2. 找到对应的 Release，点击右上角 "Edit"
  3. 滚动到底部，点击 "Delete this release"
  4. 确认删除（注意：Tag 仍会保留，需单独删除）
